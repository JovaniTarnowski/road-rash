Road Rash Native — development build

Launch the application and import your own Road Rash 1997 rerelease ISO or
extracted ROADRASH folder. Original game data is not bundled.

This application includes SDL3 (zlib licence) and stb_image (MIT licence).
Their licences are included in this directory.

The port is in development. Gameplay, presentation and original-game parity
remain incomplete. See the repository's docs/PROGRESS.md for current evidence.
