**Task 3 design note.** `Race` holds the immutable routes (`routes_`, large)
next to mutable state, and `std::function` sinks capturing `this`. Plan:
move immutable data behind `std::shared_ptr<const ...>` members (routes,
tables, static spans) so a snapshot is a copy-assignment of the mutable
remainder into preallocated slots (no steady-state allocation once vector
capacities settle), plus `TrafficSystem`, `PedestrianSystem`, `TrackRing`
copies and the RNG word; `state_hash` = FNV over `snapshot()` fields plus
the systems' state. Measure copy cost before choosing between that and an
explicit byte serialiser.
