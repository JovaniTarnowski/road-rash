   member. REQUIRED by Review Focus 1 / Global Constraints: `TrackRing` stores
   `const Course&`; with a value member, the spec's own `std::move(setup)` test invalidates
   the ring's reference (reproduced: `Track ring: missing course node` at tick 79 after a
   move; ASan-clean but logically dangling). Every other pointed-to object was already
   heap-owned. Consumers use `*course` / `course->`. Task 2+ call sites must use the pointer
   form. If the orchestrator insists on the exact value-member shape, `TrackRing` must stop
   holding a reference first (owns `src/track_ring.*`, out of scope here).
2. `tests/race_test.cpp` touched (3-line mechanical path fix) although outside Owns — full-tree
   build fails otherwise. No behavior change.
3. ASan tree lives at `../rr-wt-26-1-asan` (sibling of the worktree, same pattern as
   `build-wt-26-1` inside the worktree); both are untracked build dirs, not committed.

   harness skips), but byte-identical including the skip — the harness is untouched, as required.
