## Findings and applied changes

### Shared source ownership must survive validation

OMP SimReplay reports `git stash push --include-untracked` to test pristine HEAD;
RenderInfra and Plan16Combat also describe stash/restore cycles. A private build
can still read changing shared source. CollisionUnify reports accidentally
removing header methods; MusicRace receives a parent correction for lost
namespace/class openers and a missing method. These are concrete edit and
coordination failures, not evidence that every concurrent change was damaged.

Canonical AGENTS now prohibits whole-tree stashing during concurrent work,
requires narrow diff/header inspection and an affected-target compile, and
requires files to exist before CMake registration. It recognizes the owner's
shared-checkout preference recorded in Claude's integration thread; isolation
must not silently override an explicit request to work in `native-port/`.
Baseline comparisons can use an isolated checkout while implementation stays
where authorized. Worktrees remain useful when the owner permits them.

The resource registry was empty during this review even though the checkout
contained substantial live changes. Its cooperative claims are not automatically
adopted by OMP or Claude. Canonical instructions now explicitly tell incoming
agents to check OMP's latest handoff/ownership before taking an implementation
slice. This review does not claim automatic client integration or enforcement.

### Recovered facts need supersession and asset identity

HazardsTrace/PoliceSpawnTrace initially label pool `0x004c1274`, template
`0x0046dde0`, type `0x20` as cops and conclude there are no pedestrians. The owner
then identifies the person on crutches. Claude's artwork/dispatch investigation
and current [recovered facts](../REVERSE_ENGINEERING.md) / plan 24 correct the pool
to pedestrians; police bikes use the rider path. RotationFixture later receives
messages asserting the old cop interpretation and correctly reports the conflict.
The old census now has an explicit supersession banner, but its historical body
still includes the obsolete cop statement.

AGENTS now requires reading supersession notices and checking spawn, think/draw
and asset families before reusing an actor label. A string search or presumed
pool name cannot prove an entity absent. This is a workflow correction, not a
new independent runtime verification of pedestrians or traffic lights. Existing
plan 24 capture/pixel acceptance remains open.

### LSP works in OMP; the database drifted

OMP `01a12f43…` verifies clangd status, symbols, diagnostics, definition and
references via `xd://lsp` after adding workspace `lsp.json`. TOOLING still said
OMP had no server. The setup transcript also flagged a missing car-contact source
in the compilation database. The new read-only check independently confirms
that stale entry and newer CMake configuration.

Updated TOOLING and AGENTS with observed OMP setup and reload/fallback steps.
Added `tools/agent_lsp.py`, `make lsp-check` and compile-database reporting in
`make doctor`. The check exits nonzero for absent/malformed/empty databases,
missing sources or configuration newer than the database. Optional `--check`
runs a bounded clangd parse and preserves its exit code. It never configures,
builds, replaces symlinks or reloads another client's server. Timestamps and file
presence are only a freshness hint, not proof of exact compile flags or client
integration. Refresh into an owned build after the relevant source settles.

### Long tasks need usable budget handoffs and forward progress

Many OMP children reach their 200-request soft budget while finishing syntax,
checks or notes. Their results are sometimes emitted through client tools rather
than a final conversational answer. Preserve the concrete incomplete state in a
uniquely named docs handoff before the boundary. Analysis-only scratch notes
cannot be the only durable project record.

The long OMP parent has 85 textual `Standing down` occurrences and 101 `Audit:`
occurrences in the extracted snapshot. These are string counts, not 85 distinct
verified failures. The repeated unchanged audits show avoidable output and
request cost. AGENTS now says to advance an independent authorized slice when
possible and avoid repeated identical no-change audits, without widening scope
or claiming blocked acceptance complete.

### Session review should be repeatable

Added `tools/agent_sessions.py` / `make agent-sessions`: read-only adapters for
Codex active/archived JSONL, Claude project/subagent JSONL, OMP parents/children,
and OpenCode modern SQLite plus legacy session metadata. Project membership
uses cwd/project IDs, not a prompt mentioning rr. The tool records snapshot
hashes, complete records, malformed records, partial append tails, missing stores
and explicit OpenCode gaps. It does not read credential/configuration stores or modify client
configuration. Conversation text export is opt-in and must be outside this Git
repository; inspect it locally and never commit it.

- Existing simulation diagnostic pins, goldens, captures, packaging and device
  claims were not changed. No agent global configuration was modified, and no
  other client was restarted or messaged.
